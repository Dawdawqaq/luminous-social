## 前端使用

正式素材位于 `frontend/public/brand/level-stars/`，分段规则统一定义在 `frontend/src/components/ui/levelStars.ts`。
展示组件为 `frontend/src/components/ui/LevelBadge.tsx`，接受真实整数等级 1—18；缺失、非整数和越界数据不显示，不默认伪造为 1 级。
个人与社区内等级可通过 `scope` 区分可访问名称，分别传入各自等级值，不负责经验累计或等级计算。

```tsx
<LevelBadge level={personalLevel} />
<LevelBadge level={communityLevel} scope="community" />
```

这些参数需由后续成长接口提供。当前用户、帖子、评论接口没有等级字段，因此本轮不修改其返回约定，也不在真实账户页面展示示例等级。
