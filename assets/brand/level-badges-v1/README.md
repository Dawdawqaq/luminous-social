## 设计

沿用用户已确认的 assets/brand/luminous-star-blue-corner-soft-preview-20261011.png，星星保持黄色主体、蓝色右角、柔和连接与黑色轮廓。

等级数字为 LV 1—18，每三等级变化一次底色或内框：白底、淡黄、浅蓝、蓝底白字、细黄内框、加粗黄内线。每级不堆叠新道具或装饰。阶段分组仅是这一版的视觉建议，不新增升级规则或权益。

实际高度为 28px；大图预览放大到 42px，便于检查。支持浅色和深色背景。
